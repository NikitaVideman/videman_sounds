# Videman Sounds
Данный ресурспак для Minecraft добавляет новую озвучку мобам на русском языке в комичном стиле.

### Что озвучено в этой версии
1. Житель
2. Железный голем
3. Странствующий торговец
4. Разбойник
5. Ведьма
## Установка
1. Скачай файл .zip — не распаковывай!
1. Запусти Minecraft → открой Настройки → Наборы ресурсов
1. Нажми Открыть папку наборов ресурсов
1. Скопируй .zip в открывшуюся папку
1. Вернись в игру → выбери пак → нажми Готово
