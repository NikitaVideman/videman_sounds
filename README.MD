# Videman Sounds

Этот ресурспак для Minecraft предоставляет новую озвучку мобам на русском языке в юмористическом стиле.

### Что озвучено

1. Житель
2. Железный голем
3. Странствующий торговец
4. Разбойник
5. Ведьма
6. Зомби-житель
7. Зомби
8. Скелет
9. Визер-скелет

Дополнительно:

1. Добавлен звук приземления слизи
2. Исправлена ошибка с субтитрами (до этой версии они не отображались)

### Установка

1. Скачайте файл .zip без распаковки.
2. Запустите Minecraft, откройте Настройки и перейдите в раздел «Наборы ресурсов».
3. Нажмите «Открыть папку наборов ресурсов».
4. Скопируйте .zip в открывшуюся папку.
5. Вернитесь в игру, выберите новый пак и нажмите «Готово».
